COMPARATIVE EXPERIMENT

When ordinary page input becomes executable code

A small exhibit-planning application demonstrates DOM-based script injection and unsafe runtime evaluation. The examples stay entirely within this local project.

01 · Vulnerable

Observation Wall: Script Injection

User comments are inserted as HTML, creating an executable event-handler path.

01 · Corrected

Observation Wall: Text Only

Untrusted comments are inserted using textContent and a restrictive CSP.

02 · Vulnerable

Lantern Count: eval()

A calculation field executes the entire entered string as JavaScript.

02 · Corrected

Lantern Count: Explicit Arithmetic

Inputs are parsed as limited arithmetic with no dynamic code execution.

This project uses local example input only and does not store or transmit personal data.
